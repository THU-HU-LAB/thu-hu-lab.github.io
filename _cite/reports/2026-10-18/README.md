## 核验依据和重要修正

- Crossref：精确 DOI 检索；缺 DOI 时用题名检索，并核对作者。`verification.json` 保留原表行、候选元数据、首轮匹配分数和最终复核状态；相似题名本身不等于同一篇论文。
- 原表第 123 条：`10.1109/wcme1m48965.2019.00161` 中的数字 `1` 应为字母 `i`，正确 DOI 为 `10.1109/wcmeim48965.2019.00161`。正确 DOI 的题名与七名作者吻合。
- 原表第 55 条：利用[清华机械系官方新闻](https://me.tsinghua.edu.cn/info/1003/3145.htm)核实《集成电路装备光刻机发展前沿与未来挑战》，补入 DOI `10.1360/SSI-2023-0378`。
- 原表第 63、161 条：Crossref 作者信息缺失，分别用[机械工程学报 2023 年论文页](https://qikan.cmes.org/jxgcxb/EN/10.3901/JME.2023.21.099)、[2016 年论文页](https://qikan.cmes.org/jxgcxb/EN/10.3901/JME.2016.11.042)补全作者。
- 原表第 97 条：Crossref 无记录；[清华学报官网](https://jst.tsinghuajournals.com/article/2022/4307/20220303.htm)确认题名、七名作者、DOI、卷期页码，因此仍可导入。
- 原表第 155 条：[euspen 官方 PDF](https://www.euspen.eu/knowledge-base/ICE16-P9.03.pdf)确认题名、作者、清华单位和 2016 年会议；不虚构 DOI。
- 第 116 条明确标为勘误，不与原论文合并成一条，也不计为完整研究论文。
- arXiv 通过官方作者检索 API 获取 13 条元数据，按明确 DOI 或已记录的版本对应关系合并其中 5 条。其余 8 条明确标注 `preprint`。
- 同名作者、跨领域旅游书章、独立注册的封面页、视频/补充材料组件以及尚不确定的 SSRN 版本未自动计为新论文。没有把 OpenAlex 的作者总数当作导入数量。

`review-decisions.json` 保存所有人工复核理由；`registry-supplement.json` 和 `arxiv-records.xml` 是可复现的补充元数据快照。未加入摘要、引用指标或全文到公开页面。

## 文件与后续维护

- 手动维护主数据：`_data/sources-huchuxiong.yaml`。
- 自动生成展示数据：`_data/citations.yaml`，不要只编辑这个生成文件。
- 新论文可追加至 `sources-huchuxiong.yaml` 或其他 `_data/sources-*.yaml`；成员 ORCID 继续从 `_members/*.md` 读取。
- 已核实记录带完整元数据及 `verification.sources`，后续普通预览不再为它们重复请求 Manubot。来源变化后需要主动重新核验，不能把保存的快照当作实时数据库。

从保存的核验快照重建本次导入（不重新联网核验）：

```bash
docker exec lab-website-renderer python3 _cite/tools/import_verified_library.py
```

正在运行的预览容器会在源数据变更后自动更新 citations；也可在没有另一个抓取任务运行时手动执行：

```bash
docker exec lab-website-renderer python3 _cite/cite.py
```

重新下载清单内公开 PDF（已有文件复用；失败项会再次尝试）：

```bash
python3 _cite/tools/download_public_pdfs.py _cite/reports/2026-10-18/public-pdfs.json
```
