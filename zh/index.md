# HU-LAB {#hu-lab}

HU-LAB 是清华大学机械工程系胡楚雄教授领导的课题组，围绕机器人与智能制造开展研究，涵盖精密运动控制、最优轨迹规划、多机器人安全协同、机器人感知，以及面向操作与装配的学习方法。我们结合控制理论、优化、机器学习和机电系统设计，将基础方法与工程实践相连接，并与产业界合作，面向半导体制造装备、数控加工、机器人增减材制造、自动点胶与装配，以及铁路智能运维等应用，研发算法、软件与机器人系统。
